# Onboarding media

Drop final tutorial media into this folder. The app discovers assets by filename
without code changes.

## Export

- Canvas: `1920×1080` or `2560×1440`, 16:9.
- Images: PNG for UI sharpness; JPG/WebP only for photographic content.
- Video: MP4, H.264, 30 fps, without an audio track unless narration is added later.
- Recommended video length: 6–20 seconds per slide.
- Keep the pointer movement slow and intentional.
- Use test domains and seeded demo data. Do not capture personal tabs, accounts,
  email addresses, history, bookmarks, or notifications.
- For a video thumbnail, optionally add `<name>-poster.png`.

## Required filenames

- `welcome-overview`
- `browser-install`
- `browser-pin`
- `browser-popup`
- `blockers-protection`
- `blockers-site-control`
- `blockers-link-safety`
- `analytics-blocking`
- `analytics-activity`
- `tools-overview`
- `tools-pip`
- `tools-element-blocker`
- `tools-settings`

Each name may use `.png`, `.jpg`, `.webp`, `.mp4`, `.mov`, or `.m4v`.
