Browser Monitor Privacy Policy

Last updated: August 2026

Overview

Browser Monitor is a privacy-focused browser extension designed to improve security, performance and browsing experience.

The extension follows a local-first approach. Most processing happens directly inside your browser.

Data Collection

Browser Monitor does not sell, rent or share personal information.

The extension does not collect:

  • Passwords
  • Personal messages
  • Payment information
  • Browsing history for advertising purposes

Browser Activity

Some features require access to browser tabs, URLs or page activity in order to provide security and optimization features.

This information is processed locally in your browser and is not stored on external servers unless explicitly described below.

Third-party Services

Some optional features may communicate with external services:

  • SponsorBlock API - used for community video segment information.
  • Cloudflare Worker feedback endpoint - used only when users voluntarily submit feedback.

Security Features

Browser Monitor may analyze website requests, domains and browser activity to provide protection against unwanted content, suspicious websites and unsafe resources.

Data Storage

Local settings and preferences may be stored using Chrome extension storage. This data remains on the user's device.

Your Control

Users can disable or remove Browser Monitor at any time through Chrome extension settings.
