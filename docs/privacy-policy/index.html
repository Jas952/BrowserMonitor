Browser Monitor Privacy Policy

Last updated: August 2026

1. Overview

Browser Monitor is a privacy-focused Chrome extension designed to improve browser security, privacy and browsing experience.

The extension provides features including advertisement blocking, tracker protection, distraction control, cookie banner management, custom element controls and other browser protection tools.

Browser Monitor follows a local-first approach. Most processing is performed directly inside the user's browser and browsing data is not collected for advertising or tracking purposes.

2. Information Processed by Browser Monitor

Website URLs and Domains

Browser Monitor may access website URLs and domains to provide security and content filtering features.

This access is required for features such as:

  • blocking advertisements and trackers;
  • applying filtering rules;
  • detecting unwanted or suspicious resources;
  • providing user-enabled website protection features.

Website information is processed locally whenever possible and is not stored on external servers for advertising, analytics or user profiling.

Browser Tabs

Browser Monitor may access information about currently opened browser tabs, including tab URLs and tab state.

This permission is required to provide browser monitoring features and user-requested protection tools.

Browser Monitor does not create browsing profiles, sell browsing activity, or use browsing information for advertising purposes.

Network Requests

Browser Monitor uses Chrome's Declarative Net Request API to process browser network requests locally.

This functionality is used for:

  • blocking advertisements;
  • blocking known trackers;
  • applying EasyList, EasyPrivacy and other filtering rules;
  • improving browsing privacy and security.

Local Storage

Browser Monitor uses Chrome storage features to save user preferences, settings and enabled features.

This information remains stored locally in the user's browser profile.

3. Browser Permissions Usage

Website Access

Browser Monitor requires access to websites in order to inject security and filtering scripts, modify page elements according to user settings and provide content protection features.

Tabs Permission

Used to analyze active browser tabs and provide browser monitoring features. The extension does not upload browsing history or visited websites.

Declarative Net Request

Used to block unwanted network requests, advertisements and trackers directly inside the browser.

Storage

Used to save extension configuration and user preferences.

4. Optional Permissions

Some Browser Monitor features require additional permissions. These permissions are optional and requested only when a user enables a related feature.

  • History: Used only for optional history-related features.
  • Cookies: Used only for optional cookie management features.
  • Browsing Data: Used only for optional browser data cleanup features.
  • Downloads: Used only for optional download management features.
  • Clipboard: Used only for optional clipboard-related security features.

5. Third-Party Services

Some optional features may communicate with external services.

SponsorBlock API

Browser Monitor may use SponsorBlock services to provide community-generated video segment information.

This service is used only for the requested functionality and is not used for advertising or user tracking.

Feedback Services

If a user voluntarily submits feedback, technical information required to process the request may be transmitted.

Submitting feedback is optional.

6. Data Collection and Sharing

Browser Monitor does not:

  • sell user data;
  • rent user data;
  • share personal information with advertisers;
  • create advertising profiles;
  • track users across websites.

Data is only transmitted when:

  • a user explicitly enables a feature requiring an external service;
  • a user voluntarily submits feedback.

7. Security and Privacy Features

Browser Monitor analyzes websites and browser activity only to provide security, privacy and customization features requested by the user.

The extension does not collect passwords, payment information, personal messages or private communications.

8. User Control

Users can disable individual features, remove optional permissions or uninstall Browser Monitor at any time through Chrome browser settings.

9. Changes to This Privacy Policy

This privacy policy may be updated when Browser Monitor receives new features or functionality changes.
