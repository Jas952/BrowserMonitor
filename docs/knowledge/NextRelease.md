## Install

1. Download `browser-monitor-1.1.3.zip` below.
2. Extract the archive to a permanent folder.
3. Open `chrome://extensions` and enable **Developer mode**.
4. Select **Load unpacked** and choose the extracted folder containing `manifest.json`.
5. Pin Browser Monitor to the Chrome toolbar.

For the optional macOS companion, download `BrowserMonitor.dmg`, open it, and drag Browser Monitor to Applications.
The current DMG is not Developer ID notarized, so macOS may require first-launch confirmation in **System Settings → Privacy & Security**.
