# Opportunities

Only modernization and new-tool ideas belong here. Implemented capabilities are listed in [[Features]].

## Modernization ideas

| Idea | Problem it solves |
| --- | --- |
| Site protection diagnostics | Explains why ads remain or a page stopped working and suggests a safe action. |
| Adaptive load reduction | Reduces extension work on quiet and background pages without disabling protection. |
| Smarter network rule selection | Uses the limited Manifest V3 rule budget for the most useful rules. |
| Strict, Balanced, and Compatibility profiles | Quickly strengthens protection or restores a broken site. |
| Clean Page mode | Temporarily hides popups, sticky panels, floating video, and other noise with an undo option. |
| Attention budgets | Warns when the user spends more time on a selected site than planned. |
| Clear protection levels | Replaces many technical switches with a few understandable modes. |

## New tool ideas

| Idea | Problem it solves |
| --- | --- |
| Site passport | Shows basic trust signals: HTTPS, redirects, trackers, and previous warnings. |
| Safer link opening | Opens a suspicious page with temporary restrictions. |
| Seed phrase protection | Warns before entering a recovery phrase into a suspicious web form. |
| Browser Panic | Closes dangerous tabs, clears their data, and blocks the domain in one action. |
| File disguise detection | Warns when a download looks like a document but has a dangerous file type. |
| Safer video mirror selection | Compares sources by redirects, popups, errors, and stability. |
| Video diagnostics | Explains whether playback stalls are caused by the source, network, tab, or device. |
| Spoiler hiding | Locally hides selected names and plot details until hover. |
| Suspicious review detection | Finds signs of repeated or artificial reviews without sending text outside the browser. |
| Short educational warnings | Briefly explains a recurring threat and the safe response. |
